# Bilye Kaydırağı — Gizlilik Politikası / Privacy Policy

**Bilye Kaydırağı** (mağaza adı: *Marble Workshop*) için gizlilik politikası.
Paket adı: `com.bilyeatolyesi.workshop`

Yayın adresi / Published at: **https://goktugcici.github.io/bilye-kaydiragi-privacy/**

## Özet

Oyun **hiçbir kişisel veri toplamaz**, paylaşmaz ve sunucuya göndermez. Hesap, giriş, bulut kayıt, reklam ve analitik yoktur. Oyun ilerlemesi yalnızca cihazda (Unity `PlayerPrefs`) tutulur ve cihazdan çıkmaz.

The game **collects no personal data**, shares none and sends none to a server. There is no account, sign-in, cloud save, advertising or analytics. Progress is stored only on the device (Unity `PlayerPrefs`) and never leaves it.
